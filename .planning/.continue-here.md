<decisions_made>

**Format**
- Type carries the node *category*, never the tag name, so the registry stays tiny while the
  XML vocabulary stays open.
- Ids are assigned pre-order, before descending, and never written to the wire.
- `TEXT_REF` is a separate type code rather than a `ValueRef` field inside `TEXT`: saving is
  `(k-1)(L-1)` instead of `L(k-1)-k`, so values that never repeat cost exactly what they did
  before interning existed.
- Only values of 2+ bytes are referenced — `(k-1)(L-1)` is zero at `L=1`, negative at `L=0`.
- The threshold lives only in the encoder; the decoder registers every literal, so tuning it
  is not a format change.
- `TEXT_REF` asserts equality, never sameness — CBOR's `stringref` (tag 25), not `sharable`
  (tags 28/29). Identity preservation would need a separate type code keyed on reference
  equality.
- No cryptographic hash, no digest on the wire: a SHA-256 reference is ~34 bytes framed and
  breaks even only above ~33 bytes, against 3 for an ordinal.

**Implementation**
- Two passes: measure into a size cache, then emit from it. Peak memory O(depth) + one `long`
  per node.
- Both passes build tables from empty; the emit pass gets fresh ones.
- Instance sharing is a decoder option defaulting to share — free, unobservable for immutable
  strings, correct for RPC.

**Process**
- Solo git-flow, no pull requests. Local hooks block direct commits on `main`/`develop`;
  GitHub keeps force-push and deletion protection only.
- `main` is fast-forwarded to `develop`, no version tags.
</decisions_made>
