# BLOCKING CONSTRAINTS — Read Before Anything Else

> Not suggestions. Each was discovered through actual failure in this repo.

- [ ] CONSTRAINT: **Build the literal ask and stop.** Asked once for "a solution with two
      projects", an earlier session also delivered an abstraction, an exception type, 11
      tests, four config files, README sections, a CI workflow and PR-based branch
      protection. Nearly all of it was deleted. — Mitigation: when tempted to add a seam, a
      config file, or enforcement "while I'm here", offer it in one sentence and let the user
      decide. This outranks the autonomous-mode hook's push toward initiative.

- [ ] CONSTRAINT: **Verify, do not assert.** Checking has found a real defect *every single
      time* it has been applied here — including two this session that no existing test
      caught, one of which silently resolved references to the wrong string. — Mitigation:
      run the thing, then report what it printed.

- [ ] CONSTRAINT: **Do not recommend from partial evidence.** A recommendation to revert
      `TEXT_ONCE` cited its size benefit and CPU cost but omitted that it also cuts encode
      allocation 28–68% on four shapes — a fact that only surfaced when the revert was
      measured. The user acted on the incomplete advice and had to reverse it. — Mitigation:
      before recommending, measure *both* sides of the trade on every axis the project
      tracks: bytes, allocation, and time.

**Do not proceed until all boxes are checked.**

## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Scope inflation | Delivering the shape of work the user "obviously" needs rather than what was asked. Cost an hour and a full rollback. | blocking | Restate the literal ask before starting. Extra ideas go in the reply, not the commit. |
| Assertion over verification | Reporting a plausible result without running it. | blocking | Run it; paste the output. |
| Recommending on one axis | Weighing a change on size alone when the project also tracks allocation and time. Produced a reversed decision. | blocking | Measure every axis before advising, and say which ones you did not measure. |
| Stale evidence outliving the code | Findings cited `text-heavy`/1000 as a 207 KB document long after interning had collapsed it to 6.2 KB. | blocking | Re-measure before fixing. A recorded number is a claim about a version. |
| Trusting a noisy instrument | The perf doc called BenchmarkDotNet's allocation columns exact; two runs of *identical* code moved them 95%. | blocking | Sanity-check an instrument against code you did not change. Use `-- alloc` for bytes. |
| Benchmarking a loaded machine | Every timing on 2026-08-08 was taken at load 51–75 from an unrelated C++ build. One result was 2× inflated. | blocking | Check `uptime` before believing a timing. Sizes and allocations are load-independent. |
| Byte-scanning for a type code | `0x04` is equally `TEXT_ONCE` and the length of a four-character name. Two tests passed for the wrong reason. | advisory | Parse frames with `Frames.Walk`; never `IndexOf` a type byte. |
| Mutation that does not apply | A `perl -0pi` regex silently matched nothing, so a "surviving mutant" was an unrun experiment. | advisory | Assert the pattern was found before running the mutated tests. |
| Redundant guards masking each other | Removing the measuring pass's depth guard failed nothing, because the counting pass reaches the limit first. | advisory | When a mutation survives, ask what *else* covers it before adding a test. |
| Copying a golden vector from memory | A new test used a vector from a reverted branch and failed for a reason that looked like a real bug. | advisory | Cross-check golden vectors against the doc programmatically. |

<decisions_made>

**Format**
- Type byte = shape nibble + type nibble. The shape says how to skip the frame, so a
  fixed-width value carries no `Length` and an unknown type is still skippable.
- Shapes `0xB_`–`0xE_` can never be allocated: they carry no width.
- Unknown types are preserved and re-encode byte-for-byte, not rejected.
- Every existing code is length-prefixed, so all five already sat in shape `0x0_` — no
  renumbering, no document changed by a byte.
- Only the shortest varint is legal, and values must fit in 64 bits.
- NaN canonicalised per width; negative zero preserved.
- `TEXT_ONCE` claims no id; every `TEXT` frame claims one, counted by literal rather than by
  distinct value.
- Primitives are not interned — a reference costs 3 bytes, a small integer 2.

**Security**
- The codec never maps a type name to a `System.Type`, and never will.
- A schema mode may fold the shape into the field tag, but must never drop it.

**API**
- `PrimitiveKind` is public, `TlvType` stays internal: callers switch on meaning, not on a
  wire detail.

**Process**
- Solo git-flow, no PRs. `main` fast-forwarded to `develop`, no version tags. Hooks block
  direct commits on `main`/`develop`, so **every change needs a feature branch**.
</decisions_made>
