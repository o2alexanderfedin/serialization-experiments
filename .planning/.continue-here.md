## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention |
|---|---|---|---|
| Scope inflation | Delivering the shape of work the user "obviously" needs rather than the work requested. Cost an hour and a full rollback. | blocking | Restate the literal ask before starting. Extra ideas go in the reply, not the commit. |
| Assertion over verification | Reporting a plausible result without running it. | blocking | Run it; paste the output. |
| **Stale evidence outliving the code** | Findings 1 and 2 cited `text-heavy`/1000 as a 207 KB document with an LOH row. Value interning had since collapsed it to 6.2 KB. The findings were real but attributed to the wrong shape and magnitude for weeks. | blocking | Re-measure before fixing, not after. A recorded number is a claim about a version. |
| **Trusting a noisy instrument** | The perf doc said BenchmarkDotNet's allocation columns were "counted, not sampled" and could be trusted. Two runs of *identical* code moved `MeasureOnly` by 95%. | blocking | Sanity-check an instrument against code you did not change. `-- alloc` is the deterministic one. |
| Stale artifact read as fresh | A wait condition matched a benchmark report from the previous run, 14 hours old. | advisory | Delete prior artifacts, or wait on process exit rather than file existence. |
| Infrastructure failure read as test failure | A CI "failure" was a job cancelled at 15 min with 0 steps and no runner — GitHub Actions was in a major outage. | advisory | Check job `steps` count and `runner_name` before believing a conclusion. |
| Post-order id assignment | Building children before the parent assigns interning ids in completion order, not document order. Lengths and structure still validate; only the names come out wrong. | advisory | Assign the id before descending. Only a round-trip to source catches it. |
| Byte-scanning for a type code | `0x04` is equally `TEXT_ONCE` and the length of a four-character name. Two tests passed for the wrong reason. | advisory | Parse frames (`Frames.Walk` in the tests), never `IndexOf` a type byte. |
| Mutation that does not apply | A `perl -0pi` regex silently matched nothing, so a "surviving mutant" was really an unrun experiment. | advisory | Assert the pattern was found before running the mutated tests. |
| Redundant guards masking each other | Removing the measuring pass's depth guard failed nothing, because the counting pass reaches the limit first. | advisory | When a mutation survives, ask whether something *else* is covering it before adding a test. |

<decisions_made>

**Format**
- Type carries node *category*, never the tag name.
- Ids assigned pre-order, before descending, never written to the wire.
- `TEXT_REF` is a separate type code: saving is `(k−1)(L−1)`, so values that never repeat
  cost what they did before interning existed.
- `TEXT_ONCE` exists because a saving of zero is not free — an id spent for no gain pushes
  later references from one varint byte to two.
- Only values of 2+ bytes occurring 2+ times claim an id. The rule lives entirely in the
  encoder; the decoder learns the outcome from the type code, so it can be tuned freely.
- `TEXT_REF` asserts equality, never sameness — CBOR's `stringref` (25), not `sharable` (29).
- No cryptographic hash, no digest on the wire.
- Nesting bounded at 512 frames, on both sides, as part of the format.
- `TYPED` is opt-in and interns in a third id space, so documents without it are unchanged.

**Security**
- The codec never maps a type name to a `System.Type`. `BinaryFormatter` was removed from
  .NET 9 over exactly this, and Avro shipped three versions of one allow-list before it held.
- Unknown type names are preserved and re-encode unchanged, rather than rejected — possible
  only because frames are length-prefixed, and it is what stops the format ossifying.

**Process**
- Solo git-flow, no pull requests. Hooks block direct commits on `main`/`develop`.
- `main` is fast-forwarded to `develop`, no version tags.
</decisions_made>
